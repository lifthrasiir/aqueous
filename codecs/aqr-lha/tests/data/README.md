LHA archives of [lhasa](https://github.com/fragglet/lhasa)'s `test/archives` (ISC license,
Copyright (c) 2011-2025, Simon Howard; the files archived are the text of the GNU GPL 2 and
lhasa's own test texts), renamed by the tool that made them:

- `unix_*`: LHa for UNIX 1.14i (Debian's), headers of levels 0 to 2, `-lh5-` to `-lh7-`;
  `unix_lh6_long.lzh` has a stream of four blocks.
- `dos255e_*`: LHA 2.55e for MS-DOS: `-lh5-`, a stored file (`-lh0-`), directories (`-lhd-`).
- `amiga_lh4.lzh`: LhA 1.22 for AmigaOS, `-lh4-`.
- `os2_h3_lh5.lzh`: LHA 2.08 for OS/2, a header of level 3.
